LAUDEA ON IPHONE (no IPA needed)

1. Install Node.js (nodejs.org) on laptop.
2. Open this folder in terminal. Run:  node start.js
3. Laptop + iPhone on same Wi-Fi.
4. Find laptop IP (Windows: ipconfig -> IPv4, e.g. 192.168.1.5).
5. iPhone Safari: http://192.168.1.5:5000
6. Share -> Add to Home Screen.

Want it anywhere (no laptop)? Push folder to GitHub, deploy on Render.com
as Web Service: build = (none), start = node start.js
